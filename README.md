# Game

[Download the Windows game](HospitalCoop-FourDays.zip?raw=true).

1. Download and extract the entire ZIP.
2. Open the `HospitalCoop` folder and run `DisabilitySimulator.exe`.
3. For two-player LAN co-op, use this same build on both Windows PCs. One player hosts and the other joins on the same network.

Keep every extracted file and folder beside the executable. The EXE alone will not run.

The game lasts four shared days. Captured players spectate their teammate. When both players are captured, the next day begins and puzzle progress carries over. The fourth pair capture ends the game; both players choose Play to restart.

This repository contains the playable Windows build.
